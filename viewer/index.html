Simulating radiation damage in fusion reactor walls

Volunteers lend spare computer time to simulate what happens when a fast neutron knocks a tungsten atom out of place: a collision cascade lasting a few trillionths of a second. Each work unit counts the defects the cascade leaves behind. Thousands of them tell us how wall materials wear out.

What this can and cannot tell us

A prediction, not a measurement

No machine on Earth yet makes fusion neutrons at reactor strength, so these results cannot be checked against a real fusion wall. We compare with other published simulations and label every number a model prediction.

Pure tungsten first

Real wall materials are alloys. Simulating an alloy needs a trusted model of how its atoms push and pull on each other; we add a material only when such a model has been published and tested.

The first moments of damage

Each work unit is one neutron hit in a perfect crystal. Years of damage piling up, or sudden events like plasma disruptions and heat cycles, are beyond what these simulations can follow.

Join Nuclear@Home

Nuclear@Home runs through BOINC, the free volunteer-computing app. Your account, password and team live in BOINC; this site shows the science and the stats.

1. Install BOINC

Linux (64-bit) only for now. On Ubuntu, Debian or Raspberry Pi OS:

sudo apt install boinc-client boinc-manager

2. Add the project

In BOINC Manager choose Tools → Add project, enter the project address and create your account (username, email, password) or log in.

The project address will appear here when the invite-only beta opens.

3. Teams

Create or join a team from your account page on the project site. Your points then count for the team too.

Team join codes, approved by team managers, are coming with the beta.

Choose how your computer helps

These are BOINC Manager settings (Options → Computing preferences); they apply to every BOINC project.

You wantSetting
Use only some CPU coresComputing → "Use at most __ % of the CPUs" (each work unit uses one core)
Run only when idleComputing → "Suspend when computer is in use"
Run while on batteryComputing → untick "Suspend when computer is on battery"
Use the GPUActivity menu → "Use GPU based on preferences". BOINC sends GPU work (NVIDIA, via OpenCL) automatically when it is faster; each GPU task also uses about one CPU core
Use only the GPUOn the project site: Your account → Preferences for this project → untick "Use CPU"
Keep the computer awakeBOINC does not prevent sleep: set your system's power settings so it does not sleep while plugged in

Every finished work unit is uploaded automatically and checked by the server before it earns points. Your computer keeps no copies; the latest cascade of each computer can be viewed in 3D on the Machines and Work Units pages.
