## Goal
Measure Time Per Frame (wall-clock seconds per 1% of progress) on the volunteer's
machine and produce monotonic progress values for the BOINC client, correctly
handling suspend/resume and restarts from checkpoints.

## Interface / contract
```python
class TPFTimer:
    def __init__(self, clock: Callable[[], float] = time.monotonic) -> None: ...
    def update(self, fraction_done: float) -> list[float]:
        """Feed the latest progress (0.0-1.0). Returns any TPF samples (seconds)
        completed since the last call, one per whole percent crossed."""
    def suspend(self) -> None:
        """Pause timing (BOINC suspend). Time while suspended is not counted."""
    def resume(self) -> None: ...
    def restore(self, fraction_done: float) -> None:
        """After a restart from checkpoint: set progress without emitting samples."""
    def latest_tpf(self) -> float | None: ...

def parse_progress(log_line: str, total_steps: int) -> float | None:
    """Parse a LAMMPS thermo line and return steps/total_steps clamped to [0, 1],
    or None if the line isn't a thermo line."""
```

## Acceptance criteria
- [ ] Progress never decreases; values clamped to [0, 1]
- [ ] Suspended time excluded from TPF
- [ ] Jumping several percent in one update emits one averaged sample per percent
- [ ] `restore()` after restart emits no bogus samples
- [ ] Tests pass via `bash scripts/run-tests.sh`

## Tests that must pass
- steady progress, suspend/resume, multi-percent jump, restart restore,
  malformed log lines, progress going backward (ignored)
